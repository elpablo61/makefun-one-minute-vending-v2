## Entry

> The chocolate in coil three has been stuck since Tuesday, holding on for someone worth dropping for. You walked past. It fell.

126 characters, one line. The machine speaks in the first person, from its own world — coil, Tuesday, a snack that finally drops — with the turn landing in the last two words.

## Run

```sh
node main.ts
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
